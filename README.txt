ARTHAI3 - AR เติมคำด้วยนิ้ววิเศษ

วิธีใช้
1) อัปโหลดไฟล์ทั้งหมดขึ้น GitHub Pages หรือเปิดผ่านเว็บเซิร์ฟเวอร์
2) อนุญาตให้เบราว์เซอร์ใช้กล้อง
3) ยกนิ้วชี้หน้ากล้อง
4) ชี้ค้างที่ตัวอักษรประมาณ 0.6 วินาทีเพื่อหยิบ
5) ชี้ค้างที่ช่องว่างเพื่อวาง

หมายเหตุ
- ต้องใช้อินเทอร์เน็ต เพราะโหลด MediaPipe จาก CDN
- แนะนำ Chrome / Edge บน Android หรือแท็บเล็ต
- ใช้ไฟสว่างและให้มืออยู่ในกรอบกล้องเพื่อความแม่นยำ
