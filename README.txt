ARTHAI3 - เวอร์ชันชี้นิ้วเติมคำ

สิ่งที่แก้ไขในเวอร์ชันนี้
1. เอาพื้นหลังสีขาวของการ์ดออก ให้เห็นกล้อง/AR เต็มจอ
2. เอาปุ่ม “คำถัดไป” ออกแล้ว
3. เมื่อตอบครบคำ ระบบไปคำถัดไปอัตโนมัติ
4. แก้ระบบวางตัวอักษรใหม่ ไม่ใช้การแตะหน้าจอ
5. เพิ่มพื้นที่ดูดช่องวางให้กว้างขึ้น วางง่ายขึ้น
6. ชี้ค้างประมาณ 0.43 วินาที เพื่อหยิบ/วาง

วิธีใช้งานบน GitHub Pages
- แตกไฟล์ ZIP ก่อน
- อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์ ARTHAI3 ไปที่ Repository
- ต้องมี index.html อยู่หน้าแรกของ Repository หรือในโฟลเดอร์ที่ตั้งค่า Pages ไว้
- เปิดเว็บผ่าน https://ชื่อผู้ใช้.github.io/ARTHAI3/

หมายเหตุ
- ต้องอนุญาตใช้กล้อง
- ใช้ในที่มีแสงสว่างพอ
- แนะนำ Chrome หรือ Edge บนแท็บเล็ต/มือถือ
